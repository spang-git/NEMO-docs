NEMO workflow and instruction documentation

This documentation is to briefly introduce NEMO3.6 OGCM and to run the noCC / CC experiments via the model. 

NEMO file folders: ../

- CONFIG    (set configuration)
- EXTERNAL

- SETTE
- TOOLS
